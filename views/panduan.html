Android (Chrome)
1
Sambungkan ke WiFi yang sama

HP Android & komputer harus terhubung ke router / hotspot WiFi yang sama.

2
Buka Chrome di HP

Ketik di address bar: http://...:3000/absensi/scan

3
Izinkan Kamera & Lokasi

Ketuk Izinkan saat Chrome meminta izin kamera dan lokasi.

4
Tambah ke Homescreen (opsional)

Ketuk ⋮ → Tambahkan ke layar utama → ikon aplikasi muncul di homescreen.

iPhone / iPad (Safari)
1
Sambungkan ke WiFi yang sama

iPhone & komputer harus di WiFi / hotspot yang sama.

2
Buka Safari (bukan Chrome)

Ketik: http://...:3000/absensi/scan
⚠️ Gunakan Safari agar kamera & GPS bekerja di iOS.

3
Izinkan Kamera & Lokasi

Ketuk Izinkan saat Safari meminta izin.

4
Tambah ke Homescreen (opsional)

Ketuk ikon Bagikan (□↑) → Tambahkan ke Layar Utama → Tambahkan.

HP tidak bisa akses server? — Buka firewall

Windows Firewall mungkin memblokir koneksi dari HP. Jalankan perintah ini di Command Prompt sebagai Administrator:

netsh advfirewall firewall add rule name="Absensi-NodeJS" dir=in action=allow protocol=TCP localport=3000

Atau: Windows Defender Firewall → Allow an app → cari Node.js → centang Private & Public.

Cara Online — Akses dari Mana Saja Gratis

1
Buat akun Railway.app

Buka railway.app → Sign Up dengan GitHub.

2
Upload kode ke GitHub

Buka github.com → New Repository → upload semua file dari folder absensi-app.

3
Deploy di Railway

Di Railway → New Project → Deploy from GitHub Repo → pilih repo absensi.

4
Set Environment Variables

Di Railway → Variables → tambahkan:
SESSION_SECRET = string panjang acak
NODE_ENV = production

5
Dapat URL publik otomatis

Railway memberi URL seperti https://absensi-xxx.railway.app — bisa diakses dari HP mana saja tanpa WiFi.

⚠️ Untuk deploy online, database SQLite perlu diganti ke PostgreSQL (Railway menyediakan gratis). Hubungi pengembang untuk bantuan migrasi.
